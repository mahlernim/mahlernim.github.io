ScholarRelay Analytics Collector privacy policy

Updated September 18, 2026. Operated by Mahler Lab for private administrative use.

Access and use

The collector uses Google's read-only Analytics permission to retrieve aggregate daily store page-view and install-event counts, dates, and report metadata from the operator's own GA4 property. These data are used only to monitor ScholarRelay store activity and collection reliability. It does not request individual visitor records or change Analytics data or settings.

Storage and sharing

OAuth credentials, aggregate reports, and history are stored on the operator's computer. Credentials are kept outside the source code and dashboard directories. The dashboard contains aggregate data only and is viewed locally. Google receives the authentication and API requests needed to supply reports. This website receives no collector data.

Google user data are not sold, used for advertising, transferred to other services, or used to train AI models. Access is limited to the operator. Public store listing and search observations are collected separately without a signed-in account.

Retention and deletion

Local reports and history remain until the operator deletes them. The operator can stop collection, delete the saved reports, database and credentials, and revoke the app's access in Google Account permissions. Deleting local files does not delete the original GA4 data held by Google.

Questions or deletion requests can be sent to mahlerlabdiy@gmail.com.
