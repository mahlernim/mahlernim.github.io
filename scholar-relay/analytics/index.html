ScholarRelay Analytics Collector

A private tool operated by Mahler Lab to monitor aggregate Chrome Web Store listing activity for ScholarRelay.

The collector requests read-only Google Analytics access to retrieve daily store page-view and install-event counts from the operator's own GA4 property. It saves reports and history on the operator's computer for a local dashboard. It also records public store listing and signed-out search observations.

This is an administrative tool, separate from the ScholarRelay browser extension. It has no public sign-up and does not request access to extension users' Google accounts.
